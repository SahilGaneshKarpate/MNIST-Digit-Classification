# MNIST Digit Classification Using Neural Networks

## Project Overview

This project classifies handwritten digits (0–9) using a Neural Network built with TensorFlow and the MNIST dataset.

## Technologies Used

- Python
- TensorFlow
- NumPy
- Matplotlib
- Streamlit
- Pillow

## Project Workflow

1. Load MNIST Dataset
2. Preprocess Images
3. Build Neural Network
4. Train Model
5. Evaluate Model
6. Predict Handwritten Digit

## Files

- train_model.py
- app.py
- model.h5
- requirements.txt

## Run Project

Train Model

```bash
python train_model.py
```

Run Streamlit App

```bash
streamlit run app.py
```

## Output

- Predicts handwritten digits from uploaded images.
